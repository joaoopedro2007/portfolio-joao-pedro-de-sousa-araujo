# 💻 Deploy do Projeto

A publicação do site **“E SE PARASSE POR 24H?”** foi realizada por meio do **GitHub Pages**, um serviço de hospedagem gratuito que permite disponibilizar projetos web na internet.

Inicialmente, o projeto foi desenvolvido e organizado no **Visual Studio Code**, utilizando HTML, CSS e JavaScript para a construção da estrutura, aparência e funcionalidades do site.

Após a finalização do desenvolvimento, os arquivos foram adicionados a um repositório no **GitHub**, onde ficaram armazenados e disponíveis para gerenciamento.

Para colocar o site no ar, foi necessário acessar as configurações do repositório, na seção **Settings** > **Pages**, e definir a branch e o diretório responsáveis pela publicação dos arquivos.

Com as configurações realizadas, o **GitHub Pages** disponibilizou um link público, possibilitando que qualquer pessoa acessasse o projeto por meio de um navegador.

Por fim, foram realizados testes para conferir se o site estava funcionando corretamente, incluindo a navegação entre os quatro cenários, a exibição das informações e os elementos interativos.

Esse processo proporcionou uma experiência prática sobre como publicar e disponibilizar um projeto Front-End na internet.
