# 🎮 Pixel Verse
## 📝 Descrição do Projeto
O **PixelVerse** é um site educativo multi-página sobre a história dos videogames, seus jogos mais famosos e algumas curiosidades. O site reúne a evolução dos consoles e jogos, uma galeria com seis jogos marcantes, datas importantes e perguntas frequentes, além de uma página de contato. Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**.
* **Linguagem:** HTML5, CSS3 e JavaScript
* **Bibliotecas:** Bootstrap 5 
* **Ferramentas:** VSCode
* **Modelo de IA:** Claude
## 📊 Resultados e Aprendizados
O projeto resultou em um site educativo com cinco páginas (Início, Sobre, Galeria, Dados e Contato), com navegação entre elas e o conteúdo dividido por tema.

Ao longo do desenvolvimento, pude aprender e praticar os seguintes conhecimentos:

* **Estrutura multi-página:** organizei o conteúdo em várias páginas HTML conectadas por um menu de navegação, que aparece em todas as telas.
* **Organização do conteúdo:** separei a história dos videogames, a galeria de jogos e os dados (datas importantes e perguntas frequentes) em páginas próprias.
* **Layout responsivo:** usei o Bootstrap 5 para fazer o site se adaptar a diferentes tamanhos de tela.
* **Estilização com CSS:** criei um arquivo de estilos próprio, mantendo a mesma identidade visual em todas as páginas.
* **Recursos visuais:** usei um banner e imagens em formato SVG para ilustrar o tema de videogames.
* **Publicação web:** versionei o código com o GitHub e publiquei o site com o GitHub Pages.

O projeto me ajudou a evoluir em HTML, CSS e JavaScript, principalmente na construção de um site com várias páginas e na sua publicação online.
## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial (Claude) estritamente como ferramenta de suporte tecnológico para estruturação do HTML, estilização com CSS e simplificação do código. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
