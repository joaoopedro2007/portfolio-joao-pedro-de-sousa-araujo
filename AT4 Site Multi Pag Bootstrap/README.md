# 🎮 Pixel Verse
## 📝 Descrição do Projeto
O **PixelVerse** é um site educativo multi-página sobre a história dos videogames, seus jogos mais famosos e algumas curiosidades. O site reúne a evolução dos consoles e jogos, uma galeria com seis jogos marcantes, datas importantes e perguntas frequentes, além de uma página de contato. Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**.
* **Linguagem:** HTML5, CSS3 e JavaScript
* **Bibliotecas:** Bootstrap 5 
* **Ferramentas:** VSCode, GitHub e GitHub Pages
* **Modelo de IA:** Claude
## 📊 Resultados e Aprendizados
O projeto resultou em um site educativo com cinco páginas (Início, Sobre, Galeria, Dados e Contato), com navegação entre elas e conteúdo organizado por tema. Durante o desenvolvimento, foram trabalhados os seguintes conhecimentos:

* **Estrutura multi-página:** organização do conteúdo em páginas HTML ligadas por um menu de navegação presente em todas as telas.
* **Organização do conteúdo:** separação da história dos videogames, da galeria de jogos e dos dados (datas importantes e perguntas frequentes) em páginas próprias.
* **Layout responsivo:** uso do Bootstrap 5 para adaptar o site a diferentes tamanhos de tela.
* **Estilização com CSS:** criação de um arquivo de estilos próprio, mantendo a mesma identidade visual em todas as páginas.
* **Recursos visuais:** uso de um banner e de imagens em formato SVG para ilustrar o tema de videogames.
* **Publicação web:** versionamento do código e deploy do site com GitHub e GitHub Pages.
## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial (Claude) estritamente como ferramenta de suporte tecnológico para estruturação do HTML, estilização com CSS e simplificação do código. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
